# Installer RedM et se connecter

## Prérequis

- **Red Dead Redemption 2** (version PC légitime).
- **RedM** : client communautaire pour jouer sur des serveurs custom.

## Étapes (à adapter)

1. Installe / mets à jour **RedM** depuis le site officiel du projet.
2. Lance RedM, ajoute le serveur (nom + IP / lien **cfx.re** si vous en avez un).
3. Au premier spawn, suis le **tutorial** ou les consignes staff du serveur.

:::info À compléter
Ajoute ici le **lien d’invitation**, l’IP exacte, les mods autorisés ou interdits, et un lien vers votre Discord.
:::
