# Factions

Documente ici les factions reconnues : objectifs, territoire, hiérarchie, comment rejoindre, règles spécifiques.

- **Forces de l’ordre** : shérifs, marshals, etc.
- **Hors-la-loi** : gangs, contrats, rivalités.
- **Civils / associations** : commerce, religion, presse, etc.
